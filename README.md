# autoresearch

A general-purpose AI research agent inspired by [karpathy/autoresearch](https://github.com/karpathy/autoresearch).

## Overview

This project implements an autonomous research pipeline that can iteratively search, retrieve, reason, and synthesize information to answer complex questions.

## Key Techniques

- **Iterative retrieval**: The agent issues search queries, reads results, and decides whether more information is needed before synthesizing an answer
- **Chain-of-thought reasoning**: Explicit reasoning steps guide query generation and answer synthesis
- **Self-refinement**: The agent critiques and improves its own outputs across multiple rounds
- **Tool use**: Search, fetch, and summarize tools are composed to gather evidence
